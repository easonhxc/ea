# UniPath 1.0 — Warm Academic Design System

The production UI direction is **Warm Academic / Classic Editorial**.

## Visual principles

- Warm ivory canvas instead of stark white or blue-gray dashboards.
- Deep forest green as the primary action and identity color.
- Sage-tinted active states instead of neon gradients.
- Editorial serif typography for page and card titles; neutral sans-serif for controls and dense data.
- Fine low-contrast borders, restrained shadows, smaller radii, and more deliberate spacing.
- Data remains dense enough for admissions planning, but visual hierarchy should feel closer to an academic publication than a generic analytics SaaS.

## Core light palette

- Canvas: `#f4f1e9`
- Surface: `#fffdf8`
- Soft surface: `#f8f5ed`
- Text: `#243029`
- Muted text: `#6c746c`
- Forest primary: `#315d42`
- Forest accent: `#3f6b4d`
- Sage accent surface: `#dce7d8`

## Dark appearance

Dark mode retains the same identity using forest-black surfaces, warm ivory text, and sage accents. It should not revert to the previous blue/purple tech aesthetic.

## Typography

Display/headings use a system editorial serif stack:

`Iowan Old Style`, `Palatino Linotype`, `Book Antiqua`, `Palatino`, `Songti SC`, `STSong`, `Georgia`, serif.

Controls, tables, forms, and dense data continue to use the system sans-serif stack.

## Updated surfaces

The design system is applied to:

- Authentication / landing
- Global navigation and account area
- Mastheads and primary actions
- Overview
- Applicant Intelligence
- College list / filters / details / comparison
- Opportunity cards and Project Detail
- Roadmap
- Application Strategy and simulation
- AI Advisor
- Prediction History
- Settings and onboarding

## Theme migration

The first visit after this design update migrates the interface to Light once so existing users actually see the selected Warm Academic direction. After that, Light / Dark / System preferences are respected normally.

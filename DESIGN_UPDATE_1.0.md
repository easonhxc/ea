# UniPath 1.0 — Warm Academic UI update

This package keeps the UniPath 1.0 admissions and persistence logic intact while applying the selected UI direction: **Option 3 — Warm Academic / Classic Editorial**.

### Changes

- Rebuilt the light palette around ivory, forest green and sage.
- Rebuilt dark mode as a warm forest-dark counterpart.
- Changed major page headings and editorial card titles to a serif display stack.
- Refined navigation, active states, account identity, buttons and fields.
- Reduced SaaS-like glow, heavy shadows and oversized rounded cards.
- Unified Applicant Intelligence, College Intelligence, project, roadmap, application and advisor surfaces.
- Restyled authentication and onboarding to match the same identity.
- Added a one-time design migration so existing browser sessions see the new light direction on first visit after deployment.
- Kept Light / Dark / System appearance controls available after migration.

### Functional scope

No admissions probability, college frontier, LAC, persistence, simulator or AI logic was intentionally changed in this UI update.

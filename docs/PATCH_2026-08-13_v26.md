# UniPath v2.6 — Liberal Arts + Modern UI

Date: 2026-08-13

## What changed

### Liberal arts colleges
- Added 23 U.S. liberal arts colleges to the school catalog, bringing the modeled catalog from 127 to 150 schools.
- Added a distinct `liberal_arts_college` institution type.
- Added U.S. News 2026 National Liberal Arts College ranking context separately from National Universities.
- T30/T35/T50/T75/T100 filters now apply within each institution's own U.S. News category rather than mixing the two lists.
- Liberal arts colleges are schoolwide for the core admissions model; intended-major fit still affects recommendation priority/explanation rather than inventing direct-admit behavior.
- Common App selection can include top liberal arts colleges as aspirational options while keeping a balanced 20-school list.
- Verified ED rules were added for Williams, Claremont McKenna, Pomona, Middlebury, Bowdoin and Swarthmore. Unverified round rules intentionally fall back to RD.

### Homepage and visual system
- Rebuilt the signed-out landing page around one concise value proposition and a compact sign-in card.
- Simplified the signed-in Overview to focus on current path, next actions and application pulse.
- Reduced decorative clutter, strengthened spacing/type hierarchy, softened borders/shadows and standardized surface treatments.
- Improved responsive behavior for small screens and touch targets.

### Appearance settings
- Added System / Light / Dark appearance choices.
- Theme persists locally and System follows the operating-system preference.
- Added light-theme surface, typography, navigation, form and card overrides across the main app.

### College filters
- Added Universities + liberal arts / Universities only / Liberal arts colleges filter.
- College rows now identify liberal arts colleges and show `U.S. News LAC 2026` for that ranking system.

## Validation
- JSX/JS syntax parsed successfully for the modified core files.
- A strong Sociology test profile produced a 20-school Common App list containing 7 liberal arts colleges while retaining preferred universities such as UChicago, Northwestern, Brown and Cornell.
- A strong materials/environmental engineering test profile produced only 1 liberal arts college in the Common App 20, indicating that LACs do not automatically crowd out engineering-heavy universities.
- Full `next build` could not be completed in the isolated work environment because project dependencies were not available after install timed out; no build error was observed before that environment limitation.

## Data caveat
Admissions rates and program coverage for newly added schools are conservative seed data unless explicitly marked/verified. Rankings are display/context only and do not directly alter admission probability.

# Patch notes — 2026-08-12

This patch addresses three production issues reported during testing:

1. **Activity import enrichment**
   - Free-text sentinel values such as `unknown`, `n/a`, and `not provided` are normalized to empty/null instead of being rendered as literal outcomes.
   - Negative or impossible activity durations are rejected.
   - Common date ranges and month/year durations are normalized.
   - Completed research/projects receive conservative evidence-scope inference (`self`, `school`, `local`, etc.) only where the source supports it.
   - Concrete finished outputs can be linked back to matching activities.
   - Generic `other` activity labels no longer suppress obvious STEM/arts classification from the activity name.

2. **College model zero-result bug**
   - Added multilingual/canonical major resolution, including Chinese aliases such as `材料科学与工程` → `Materials Science & Engineering`.
   - The engine no longer silently returns zero schools when a major label is not recognized. It falls back to a clearly labeled undeclared model and surfaces a warning.
   - College filters now show a proper empty-state message when the model has schools but the current search hides them.

3. **High-school catalog expansion**
   - Expanded the initial catalog from 35 to 43 entries.
   - Added Shanghai Starriver Bilingual School, Guanghua Cambridge, Ulink Shanghai, WFLMS, SUIS Gubei/Wanyuan, SFLS and an ECNU No. 2 international/overseas-pathway directory entry.
   - Added Chinese aliases for commonly selected Shanghai schools.
   - Starriver and Guanghua include small, audited school-context signals sourced from official aggregate admissions publications. Directory-only entries receive no admissions boost.

No Supabase schema migration is required for this patch.

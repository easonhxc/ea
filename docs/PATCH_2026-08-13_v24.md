# UniPath v2.4 calibration patch

## Fixed stale-major AI import
AI Import now replaces the applicant profile instead of carrying the previous profile's primary/secondary major into a new prediction. This prevents a newly imported Sociology applicant from being silently evaluated as Materials Science.

## Revised Common App portfolio construction
The 20-school list now separates **fit** from **probability**. Low modeled probability at an ultra-selective school no longer means the school is automatically excluded from a strong applicant's aspirational set.

For sufficiently competitive profiles, a bounded number of T20 aspirational slots is reserved and selected using:
- explicit school preference, if supplied;
- exact intended-major availability;
- course-major fit;
- project-content fit;
- interdisciplinary fit;
- overall profile band.

Rank is used only to identify the T20 display/context set. It never increases the admissions probability.

Current aspirational slot bands:
- profile >= 90: up to 5 T20 aspirational slots
- profile >= 86: up to 4
- profile >= 82: up to 3
- profile >= 79: up to 1
- lower profiles: no automatic T20 slot unless future policy explicitly changes

This is portfolio design, not a claim that a student will be admitted to any T20.

## UI auditability
College Model now displays the exact major being modeled plus the profile score, aspirational T20 slot allowance, and the number of T20 schools selected. This makes stale-state or calibration errors obvious during testing.
